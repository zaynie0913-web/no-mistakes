## stub.js 的硬约束(改它之前先读)

1. **`querySelector` 绝不能按需创建元素**。
2. **`querySelectorAll` 恒返回空数组**。任何依赖它查找已渲染元素的路径
   (比如 `bindMins()` 绑定 `.mi` 输入框)在这个桩里永远测不到,只能做静态断言
   (检查生成的 HTML 里有没有正确的 class/data 属性)。r11.js 里那条"标准线分钟
   输入框"测试就是这么写的,不要假装端到端测过了。
3. **`setInterval` 必须返回真值**。返回 `0` 会让番茄暂停逻辑测不到,而测试显示通过。
4. **`textContent` 要能从 `innerHTML` 剥标签**;设 `innerHTML` 要清 `_text`。
5. **`appendChild` 的内容不在 `innerHTML` 里,读取断言要递归子节点或用 `_children`**。
   这条坑至少踩过三次(v16 早晚身体组、v18 节点条、v20 学习统计排行),每次都是
   「读 `_html` 读到空字符串就以为功能坏了」。
6. **桩不解析初始 HTML 文件里写死的静态文本**。`_text` 对未经 JS 动态赋值的元素恒为空
   —— 这不是 bug,连从 v10 就存在的 `minHint` 都是空的。遇到"元素读出来是空的"先确认
   是不是这条,别急着当成故障(v20 交付时冒烟测试撞过一次,虚惊)。
7. **`FileReaderStub`**:测导入路径用,传进去的 file 对象用 `__text` 携带内容,
   走真实的 `$("#impFile").onchange` 入口。

## 写新测试的硬要求

1. **种子数据必须走一遍和生产 `load()` 相同的字段补全**。手写 fixture 会造成假通过。
2. **拼日期键必须走 DAYCUT=4 换算**。
3. **时间相关的断言不能写死天数**。依赖"本周有几天"的期望值要动态算,或拆成单日断言。
4. **给"今天"造数据时,任务 key 必须真实存在**。`render()` 会把今天的清单快照刷新成
   当前 `minAll()`,编造的 key 会被冲掉。
5. **切片式的文案检查(禁用词/emoji)必须收窄到目标函数,且锚点要稳定**。
   v16 犯过一次(切片切到两千行外),v20 又犯了一次同类问题——这次是**锚点本身失效了**:
   有条测试靠一句注释文字定位切片结束位置,那句注释在更早的版本里被挪走后,
   `indexOf` 返回 `-1`,而 `slice(a,-1)` 在 JS 里不报错,只是把检查范围悄悄扩大到
   "从这里切到文件末尾"。这个测试因此失效了一段时间,直到 v20 常量顺序变化才意外撞见
   (切到了名言库,里面天然含有"必须"二字)。**教训:注释文字不是稳定的锚点,
   优先用函数声明、一定存在的产品文案字符串这类不容易被顺手改掉的东西。**
6. **异步要等**。`load()` / `save()` 是 `async`,不 await 就断言会读到中间态。
7. **测试失败必须先回到真实代码复现再定性**,四类:A 产品 bug / B 测试代码 bug /
   C 桩与环境 bug / D 预期值本身过时。

## 改 HTML 的硬要求

Python 字符串替换前**必须** `assert s.count(old) == 1`。

## 已知盲区

- **默写列表的渲染路径**:`querySelector` 不按需创建元素,一渲染默写条目就崩。
- **`.mi` 分钟输入框的端到端绑定**:`querySelectorAll` 恒空,见上。
- **`Store.mode === "cloud"` 分支**:没有环境可以触发。
- **360px 真机排版**:容器里没有真实浏览器。v19 交界处 `.medmenu`/`.dtlbox` 被真机验证过;
  v20 新增的 `.task.std` 复用了最低目标同一套 DOM 结构,风险相对低但**没有被真机验证过**。
